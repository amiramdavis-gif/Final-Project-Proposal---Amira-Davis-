## In a paragraph or more, detail your project. What will your software do? What features will it have? How will it be executed?

Creating the game will require using a multitude of functions built into python. I will use the random function built into python to choose a word from a list of words that I will create. In addition to this I will need to use a multitude of if statements and for loops in order to continue to prompt the user to keep guessing the chosen word. While the user is still guessing I will create the image of the hangman game using ASCII art, and if they guess wrong the program will continue to draw a body. I will have my program stop running when the user either guesses the word, or if they run out of chances and the full body of the hangman is drawn. Following the end of their turn I will prompt the user to answer the question of whether or not they would like to play another round which will restart the program or completely end their turn if they refuse to play again, ending the program.
